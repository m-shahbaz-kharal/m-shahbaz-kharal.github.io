# m-shahbaz-kharal.github.io

Personal website for [Muhammad Shahbaz](https://github.com/m-shahbaz-kharal) — post-doctoral scholar at the University of Central Florida, building high-fidelity digital twins for Sim2Real LiDAR perception.

Live at <https://m-shahbaz-kharal.github.io/>.

## Stack

Plain static site. No build step.

- `index.html` — single-page layout
- `assets/styles.css` — design system
- `assets/main.js` — LiDAR-style point-cloud canvas + subtle scroll reveals

Hosted on GitHub Pages from `main` branch root.

## Local preview

```bash
python -m http.server 8765
# then open http://localhost:8765/
```
